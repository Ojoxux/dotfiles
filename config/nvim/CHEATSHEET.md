# Neovim 早見表（あなたの LazyVim 設定）

> `<leader>` = **スペースキー**
> 困ったら **`Esc`** を押す

---

## モード（超重要）

| モード | 何ができる | 入り方 |
|--------|-----------|--------|
| Normal | 移動・コマンド | 起動時 / `Esc` |
| Insert | 文字入力 | `i` `a` `o` |
| Visual | 範囲選択 | `v` |

---

## 起動画面（ダッシュボード）

| キー | やること |
|------|----------|
| `f` | ファイルを探して開く |
| `e` | 新規ファイル |
| `r` | 最近開いたファイル |
| `g` | テキスト検索 |
| `p` | プロジェクト一覧 |
| `q` | 終了 |

---

## これだけ覚えれば生きられる

| やりたいこと | 操作 |
|-------------|------|
| 入力開始 | `i` |
| 入力終了 | `Esc` |
| 保存 | `Space` → `w` |
| 終了 | `Space` → `q` |
| 保存して終了 | `Esc` → `:wq` → Enter |
| 保存せず終了 | `Esc` → `:q!` → Enter |
| ファイルを開く | `Space` → `Space`（2回） |
| ファイル一覧 | `Space` → `e` |
| 元に戻す | `u` |
| 行削除 | `dd` |

---

| キー | 動き |
|------|------|
| `h` `j` `k` `l` | 左 下 上 右 |
| `w` | 次の単語 |
| `b` | 前の単語 |
| `0` | 行頭 |
| `^` | 行の最初の文字 |
| `$` | 行末 |
| `gg` | ファイル先頭 |
| `G` | ファイル末尾 |
| `Ctrl+d` | 半画面下（中央寄せ） |
| `Ctrl+u` | 半画面上（中央寄せ） |

---

## 編集

| キー | 動き |
|------|------|
| `i` | カーソル位置から入力 |
| `a` | カーソルの右から入力 |
| `A` | 行末から入力 |
| `o` | 下に新行して入力 |
| `O` | 上に新行して入力 |
| `x` | 1文字削除 |
| `dd` | 行ごと削除 |
| `yy` | 行コピー |
| `p` | ペースト |
| `u` | 元に戻す |
| `Ctrl+r` | やり直し |

---

## コロンコマンド（`Esc` してから）

画面の **一番下** に出る。打って **Enter**。

| コマンド | 意味 |
|----------|------|
| `:w` | 保存 |
| `:q` | 終了 |
| `:wq` | 保存して終了 |
| `:q!` | 保存せず強制終了 |
| `:e ファイル名` | ファイルを開く |

---

## LazyVim ショートカット（Space = leader）

| キー | やること |
|------|----------|
| `Space`（待つ） | ショートカット一覧（which-key） |
| `Space` `Space` | ファイル検索 |
| `Space` `e` | ファイルツリー |
| `Space` `w` | 保存 |
| `Space` `q` | 終了 |
| `Space` `f` `f` | ファイル検索 |
| `Space` `f` `g` | テキスト検索 |
| `Shift+h` | 前のバッファ |
| `Shift+l` | 次のバッファ |

## 分割画面

| キー | やること |
|------|----------|
| `Space` `sv` | 縦に分割 |
| `Space` `sh` | 横に分割 |
| `Ctrl+w` `h/j/k/l` | 分割間を移動 |
| `Space` `sx` | 今の分割を閉じる |

---

## 検索

| キー | やること |
|------|----------|
| `/` 文字列 | 下方向に検索 |
| `?` 文字列 | 上方向に検索 |
| `n` | 次の一致 |
| `N` | 前の一致 |
| `Esc` | 検索終了 |

---

## 困ったとき

| 症状 | 対処 |
|------|------|
| 文字が打てない | `i` を押す |
| 変な画面 | `Esc` を連打 |
| コマンドが打てない | まず `Esc`、それから `:` |
| 通知が邪魔 | `Space` `s` `n` `d` で消す |
| 全部リセットしたい | `Esc` → `:qa!` → Enter |

---

## 1日の基本ループ

```
nvim
  → f（ファイルを開く）
  → i（入力）
  → Esc
  → Space w（保存）
  → Space q（終了）
```
